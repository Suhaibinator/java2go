# Sol checkpoint 206: boxing before reference widening

Declared method selection now boxes a primitive to its canonical Java wrapper before applying reference widening. This admits int to Comparable and Comparable<Integer>, along with the corresponding Long, Boolean and Character contracts. It preserves the formal declaration and generic argument origins, so wrong wrapper arguments, invariant Comparable<Number>, arrays and source or foreign homonyms remain rejected. The fix uses the existing reference-conversion proof and does not change runtime casts or identity.

The unchanged boxed-method-reference runtime fixture now passes in normal and race compiler runs and retains its fresh installed-JDK21 observation. The final formatted source passed 20 fresh stages: eight parent PASSes, 34 subcase PASSes and all six default/F1 build, test-compilation and lint profiles. Earlier qualification on the same production postimage passed 36 parent checks, including 14 regional regressions in each mode; those results remain separately attributed to that earlier source. Formatting equivalence and all Java/body literals were checked before the final run. The coordinator independently checked the source, raw receipts, output hashes, binary metadata and lifecycle evidence. Nested plain Go subprocesses receive no race credit.

A formatting-proof attempt initially treated import ordering as significant and failed when gofmt reordered imports. That attempt remains preserved; the corrected proof compares import specifications as an exact multiset and body literals in order. No Java fixture, expected result, semantic assertion or production repair was changed.

This checkpoint does not claim a passing full hosted CI run, full runtime rerun, Netty application parity or universal Java support. The original Supplier28, Gson112 and Netty1220 acceptance gates remain open. Separate qualified work has passed both original Netty graph resolution gates and the runtime FIFO allocation checks; those changes await their own integration checkpoints.
