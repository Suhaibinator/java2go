# Java `String()` is not `toString()`

Supplemental, dependency-free, multi-package reproducer. `CapitalText.String()` is an ordinary Java method; direct and Object-erased `String.valueOf` and concatenation must use default `Object.toString()` with its virtual `hashCode()` callback, without invoking `String()`. `RealText.toString()` is a true override control. The source asserts callback counts and prints observations for seeds 17, 41, and 97. The three Java files are copied byte-for-byte from the original private probe; no production or frozen Gson input was altered.

`expected.seed-*.stdout` and `expected.seed-*.stderr` were copied from the first actual JDK 21 process of each seed. `oracle.json` records all nine JDK executions, their raw hashes, zero exits, explicit Java home and javac flags, source hashes, prepared-runner hash, implementation pins, and audit provenance. The full raw attempt and generated Go evidence is in the separately verified `capital-string-collision-checkin.tar.gz` bundle, whose hash is recorded there. No expected stream was invented.

The published implementation `bdbefca9bbf98ed65321650b5ab84fc90278650b` converted this Java project but its generated Go failed to build at `undefined: Integer` in `Main.go`; published runtime parity is unclassified. The immutable final26 snapshot converted and built, then failed the first assertion in each of nine runs: it invoked `String()` instead of default object text. Consequently, the later true-`toString()` control was reached by the JVM but not by final26. This remains a supplemental reproducer, not a replacement for the full Gson application.

To reproduce the JVM oracle with explicit JDK 21, compile `src/main/java/probe/model/CapitalText.java`, `RealText.java`, and `src/main/java/probe/app/Main.java` with `javac --release 21 -encoding UTF-8`; then run `probe.app.Main` with each declared seed three times in fresh processes. The recorded differential runner and raw evidence bundle provide bounded process execution and exact hashes.
